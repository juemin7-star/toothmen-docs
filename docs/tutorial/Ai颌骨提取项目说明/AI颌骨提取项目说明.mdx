# ToothMen-DentiPro-AI颌骨提取项目说明



## 项目简介

​      

​       该项目基于 Apache License2.0的开源项目Slicer DentalSegmentator（https://github.com/gaudot/SlicerDentalSegmentator?tab=readme-ov-file）深度优化并引入ToothMen-DentiPro的工作流中，是目前AI颌骨提取领域的一项代表性技术。ToothMen基于该项技术现开发了ToothMen-DentiPro社区版以及ToothMen-DentiPro黑金版定制插件，两款插件均是ToothMen-DentiPro综合辅助软件的免费而强大的医学影响处理模块。

​      该模块可以借助本地GPU的超强AI算力，在3-5分钟完成对：上颅骨&上颌骨&下颌骨&上牙&下牙&下颌管等结构的快速精准分割，相对与原版不同的是，ToothMen将其成功引入了ToothMen-DentiPro（基于Blender4.5.5LTS）的工作流，目前，经过深度优化后的版本，支持任何格式（RAR.ZIP.7Z,DCM)的DICOM数据，并支持自动命名，自动归类，自动后处理优化，以及支持无人值守批量提取。该优化后的版本可以一键直装，自动匹配计算机硬件，自动适配及调用CUDA显卡核心，真正实现一键无忧部署与稳定高品质输出。



<img src="https://github.com/gaudot/SlicerDentalSegmentator/raw/main/Screenshots/dentalsegmentator_example.png" style={{zoom: '67%'}} />



​       DentalSegmentator 基于 nnU-Net 框架。该测试基于 470 次牙颌面 CT 和 CBCT 扫描进行训练，并在 7 所机构的 256 份 CT 和 CBCT 扫描的保留测试数据集中进行评估。经过众多高度多样化数据集的结果表明，该工具能够为牙颌面CBCT 扫描提供全自动且稳健的多类分割，且不受扫描视野影响。相关论文如下：
