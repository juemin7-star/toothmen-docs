# ToothMen DentiPro 主程序安装说明

欢迎使用 ToothMen DentiPro 牙科诊所管理系统。本指南将帮助您完成主程序的安装和配置。

## 系统要求

### 硬件要求
- **处理器**: Intel Core i5 或更高
- **内存**: 8GB RAM 或更高
- **存储**: 至少 20GB 可用空间
- **显示器**: 1920x1080 分辨率或更高

### 软件要求
- **操作系统**: Windows 10/11 64位
- **.NET Framework**: 4.8 或更高版本
- **数据库**: SQL Server 2019 Express 或更高版本

## 安装步骤

### 步骤 1: 下载安装包
1. 访问 ToothMen 官方网站下载页面
2. 下载最新版本的 ToothMen DentiPro 安装包
3. 确保下载的文件完整无损

### 步骤 2: 运行安装程序
1. 双击安装包文件 `ToothMen_DentiPro_Setup.exe`
2. 选择安装语言（中文/英文）
3. 阅读并接受许可协议
4. 选择安装目录（建议使用默认路径）

### 步骤 3: 数据库配置
1. 安装程序会自动检测 SQL Server 实例
2. 如果未检测到，请手动指定 SQL Server 连接信息
3. 创建数据库用户和密码
4. 等待数据库初始化完成

### 步骤 4: 系统配置
1. 配置诊所基本信息
2. 设置管理员账户
3. 配置网络连接
4. 设置数据备份计划

### 步骤 5: 完成安装
1. 点击"完成"按钮
2. 系统会自动启动 ToothMen DentiPro
3. 使用管理员账户登录系统

## 常见问题

### Q1: 安装过程中出现错误怎么办？
A: 请检查系统是否满足最低要求，确保有足够的磁盘空间和内存。

### Q2: 数据库连接失败怎么办？
A: 请确保 SQL Server 服务正在运行，防火墙允许相关端口通信。

### Q3: 如何卸载程序？
A: 通过控制面板的"程序和功能"卸载 ToothMen DentiPro。
