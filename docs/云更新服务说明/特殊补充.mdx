# 注册规则特殊说明

ToothMen_DentiPro_CH_SC_UICP-（260327）春节后华南后配置更新说明

## 更新内容

###    260327-1 剖面系统重写

1. 重写剖面系统，解决直播卡屏问题。解决闪烁问题，提高推流速度。

2. **自由和精确窗口互斥**，一次只能打开一个，防止数据紊乱。

3. **解除窗口强制全屏**，可以自由缩小或关闭（但没太大交互必要性）。

4. **自由和精确剖面增加左侧显示数据列表功能**，减少窗口切换。

5. **新增网格减面工具**，解决网格重构后导致面数太大以及增加运行效率。

###   260327-2 增量修复钛网部分

1. **新增钛网边框厚度控制**。小改动钛网UI。

2. **修复钛网数据修复及环境配置历史遗留问题**及特殊幽灵数据影响运行问题。
