# 账户注册&验证&更新下载·限流/封禁/封控规则



## 特别说明



1，为保障ToothMen_DentiPro_CH·正常用户的注册&激活&软件更新检查与下载效率，特采用如下限制规则。

2，该规则对正常使用场景执行了极其宽泛的规则，在正常使用情况下不会触发，但对于恶意违规用户，执行永久封禁，不予解封且永久不可再次注册。

3，封禁执行邮箱加设备双重封禁，设备端以实际CPU设备码为核心凭据。



## 1·验证码发送&验证激活封禁规则

| 模块       | 规则               | 阈值                | 触发后提示                       |
| ---------- | ------------------ | ------------------- | -------------------------------- |
| 发送验证码 | 发送冷却/验证码有效期 | 5分钟/次          | 提示剩余等待时间                 |
| 发送验证码 | 24小时阶梯限制（L1） | 同设备24小时发送次数>25次 | 进入L1保护期（30分钟）         |
| 发送验证码 | 24小时阶梯限制（L2） | 同设备24小时发送次数>35次 | 进入L2保护期（6小时）          |
| 发送验证码 | 24小时阶梯限制（L3） | 同设备24小时发送次数>50次 | 进入L3保护期（72小时）         |
| 发送验证码 | 永久封禁触发       | 同设备24小时发送次数>55次 | 触发永久封禁（邮箱加设备同时封禁） |
| 验证激活   | 分钟级验证限制     | 每分钟最多6次       | 提示验证过频并给出等待时间       |
| 验证激活   | 失败计数短窗       | 10分钟失败≥6次      | 进入L1保护期                     |
| 验证激活   | 失败计数中窗       | 24小时失败≥15次     | 进入L2保护期                     |
| 验证激活   | 7天阶梯升级        | 7天内高阶命中≥3次   | 进入L3保护期                     |
| 风险加权   | 同设备IP切换异常   | 24小时内IP去重数>8  | 仅提升风险权重，不单独永久封禁   |
| 解除策略   | 后台解除封禁       | 按邮箱或设备码解除  | 误操作可需申请管理员操作             |

备注：‘发送验证码’特指用户注册页面的“发送验证码”按钮。‘验证激活’特指用户注册页面的‘验证激活’按钮。

## 2·更新检查&下载检查封控规则（手动触发）

说明：以下规则仅作用于用户**手动点击**更新相关按钮（如“执行在线数据库更新检查”“执行在线补丁包更新检查”“数据库卡片打开链接”）；

​           自动检查流程不计入本规则。并且，上述按钮只能在用户完成验证并登录成功情况下才能正常使用。

| 模块         | 规则                 | 阈值                    | 触发后提示                         |
| ------------ | -------------------- | ----------------------- | ---------------------------------- |
| 下载检查封控 | 手动检测冷却         | 15秒                    | 提示剩余等待时间                   |
| 下载检查封控 | 24小时阶梯限制（L1） | 手动检测次数>80         | 进入L1保护期（30分钟）             |
| 下载检查封控 | 24小时阶梯限制（L2） | 手动检测次数>150        | 进入L2保护期（6小时）              |
| 下载检查封控 | 24小时阶梯限制（L3） | 手动检测次数>180        | 进入L3保护期（48小时）             |
| 解除策略     | 后台解除下载管控     | 按邮箱或设备码解除 | 误操作可需申请管理员操作 |

备注（下载封控规则受影响按钮）：
1) 数据库下载页：执行在线数据库更新检查
2) 数据库下载页：更新卡片内“打开链接”
3) 补丁包更新页：执行在线补丁包更新检查
