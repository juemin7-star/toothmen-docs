# 注册&验证&更新下载·限流/封禁/封控规则



## 特别说明



1，为保障ToothMen_DentiPro_CH·正常用户的注册&激活&软件更新检查与下载效率，特采用如下限制规则。

2，该规则对正常使用场景的限制极其宽泛，在正常使用情况下不会触发，但对于恶意违规用户，执行永久封禁，不予解封且永久不可再次注册。

3，封禁执行邮箱加设备双重封禁，设备端以实际CPU设备码为核心凭据。

4，如确有误操作导致的误封禁&封控，可申请管理员操作，核实后，可准许放行。



## 1·验证码发送&验证激活封禁规则（手动触发）

| 模块       | 规则               | 阈值                | 触发后提示                       |
| ---------- | ------------------ | ------------------- | -------------------------------- |
| 发送验证码 | 发送冷却/验证码有效期 | 5分钟/次          | 提示剩余等待时间                 |
| 发送验证码 | 24小时阶梯限制（L1） | 同设备24小时内发送次数>25次 | 进入L1保护期（30分钟）         |
| 发送验证码 | 24小时阶梯限制（L2） | 同设备24小时内发送次数>35次 | 进入L2保护期（6小时）          |
| 发送验证码 | 24小时阶梯限制（L3） | 同设备24小时内发送次数>50次 | 进入L3保护期（72小时）         |
| 发送验证码 | 触发永久封禁     | 同设备24小时内发送次数>55次 | 触发永久封禁（邮箱加设备双封禁） |
| 验证激活   | 分钟级验证限制     | 每分钟最多6次       | 提示验证过频并给出等待时间       |
| 验证激活   | 失败计数短窗（L1） | 10分钟内失败≥6次     | 进入L1保护期（15分钟）           |
| 验证激活   | 失败计数中窗（L2） | 24小时内失败≥15次    | 进入L2保护期（6小时）            |
| 验证激活   | 7天阶梯升级（L3）  | 7天内高阶命中≥3次   | 进入L3保护期（72小时）           |
| 解除封禁   | 需申请管理员介入      | 按邮箱或设备码解除          | 误操作可需申请管理员操作         |

备注：‘发送验证码’特指用户在注册页面点击“发送验证码”按钮。‘验证激活’特指用户在注册页面点击‘验证激活’按钮。

## 2·更新检查&下载封控规则（手动触发）

说明：以下规则仅作用于用户**手动点击**更新相关按钮（如“执行在线数据库更新检查”“执行在线补丁包更新检查”“数据库卡片打开链接”）；

​           自动检查流程不计入本规则。并且，上述按钮只能在用户完成验证并登录成功情况下才能正常使用。

| 模块         | 规则                 | 阈值                    | 触发后提示                         |
| ------------ | -------------------- | ----------------------- | ---------------------------------- |
| 更新检查&下载 | 手动检测冷却         | 15秒                    | 提示剩余等待时间                   |
| 更新检查&下载 | 24小时阶梯限制（L1） | 24小时内手动更新检测次数>80  | 进入L1保护期（30分钟）             |
| 更新检查&下载 | 24小时阶梯限制（L2） | 24小时内手动更新检测次数>150 | 进入L2保护期（6小时）              |
| 更新检查&下载 | 24小时阶梯限制（L3） | 24小时内手动更新检测次数>180 | 进入L3保护期（48小时）             |
| 解除封控   | 需申请管理员介入 | 按邮箱或设备码解除 | 误操作可需申请管理员操作 |

备注（受更新检查&下载封控规则影响按钮）：
1) 数据库下载页：执行在线数据库更新检查
2) 数据库下载页：更新卡片内“打开链接”
3) 补丁包更新页：执行在线补丁包更新检查

## 3·特殊：短窗频控（硬限流）规则（手动触发）

说明：本节为短时间窗口内的“硬限流”规则，与阶梯惩罚并行生效。触发后直接返回429（请求过于频繁），窗口结束后自动恢复，不进入L1/L2/L3保护期。

| 模块         | 规则                           | 阈值                 | 触发后提示                               |
| ------------ | ------------------------------ | -------------------- | ---------------------------------------- |
| 风险加权 | 同设备IP切换异常 | 24小时内IP去重数>8 | 仅提升风险权重，不单独永久封禁 |
| 发送验证码   | IP桶限流      | 同IP 60秒内最多20次 | 返回429，请求过于频繁，请稍后再试         |
| 发送验证码   | 业务键限流（邮箱+设备）        | 同邮箱同设备60秒8次 | 返回429，请求过于频繁，请稍后再试         |
| 验证激活     | IP桶限流      | 同IP 60秒内最多30次 | 返回429，请求过于频繁，请稍后再试         |
| 验证激活     | 业务键限流（设备）             | 同设备60秒内最多24次 | 返回429，请求过于频繁，请稍后再试        |

备注：本节规则是短窗拦截，不等同于“24小时阶梯限制”与“永久封禁触发”。
