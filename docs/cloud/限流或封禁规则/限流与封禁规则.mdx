# 账户限流与封禁规则



说明：为保障ToothMen_DentiPro_CH·用户使用效率，规范服务器更新下载行为，ToothMen_DentiPro_CH·针对邮箱注册与验证流程采用限制规则，详情如下：



| 模块       | 规则               | 阈值                | 触发后提示                       |
| ---------- | ------------------ | ------------------- | -------------------------------- |
| 发送验证码 | 发送冷却           | 5分钟               | 提示剩余等待时间                 |
| 发送验证码 | 设备24小时发送上限 | 同设备24小时最多5次 | 提示设备24小时上限并给出剩余时间 |
| 验证激活   | 分钟级验证限制     | 每分钟最多6次       | 提示验证过频并给出等待时间       |
| 验证激活   | 失败计数短窗       | 10分钟失败≥6次      | 进入L1保护期                     |
| 验证激活   | 失败计数中窗       | 24小时失败≥15次     | 进入L2保护期                     |
| 验证激活   | 7天阶梯升级        | 7天内高阶命中≥3次   | 进入L3保护期                     |
| 风险加权   | 同设备IP切换异常   | 24小时内IP去重数>8  | 仅提升风险权重，不单独永久封禁   |
