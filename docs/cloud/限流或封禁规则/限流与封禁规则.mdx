# 注册&验证&更新下载·限流/封禁/封控规则



## 特别说明



1，为保障ToothMen_DentiPro_CH·正常用户的注册&激活&软件更新检查与下载效率，特采用如下限制规则。

2，该规则对正常使用场景的限制极其宽泛，在正常使用情况下不会触发，但对于恶意违规用户，执行永久封禁，不予解封且永久不可再次注册。

3，封禁执行邮箱加设备双重封禁，设备端以实际CPU设备码为核心凭据。

4，如确有误操作导致的误封禁&封控，可申请管理员操作，核实后，可准许放行。

5，本规则定期更新。



## 1·验证码发送&验证激活规则（手动触发）

| 模块       | 规则                    | 阈值                            | 触发后提示                                 |
| ---------- | ----------------------- | ------------------------------- | ------------------------------------------ |
| 发送验证码 | 发送冷却/验证码有效期   | 5分钟/次                        | 提示剩余等待时间                           |
| 发送验证码 | 24小时常规上限          | 24小时内发送次数≥5              | 触发发送限制提示                           |
| 发送验证码 | 24小时阶梯限制（L1）    | 24小时内发送次数>25             | 进入L1保护期（30分钟）                     |
| 发送验证码 | 24小时阶梯限制（L2）    | 24小时内发送次数>35             | 进入L2保护期（6小时）                      |
| 发送验证码 | 24小时阶梯限制（L3）    | 24小时内发送次数>50             | 进入L3保护期（72小时）                     |
| 发送验证码 | 触发永久封禁            | 24小时内发送次数>55             | 触发永久封禁（系统自动封禁）               |
| 验证激活   | 分钟级验证限制          | 每分钟最多6次                   | 提示验证过频并给出等待时间                 |
| 验证激活   | 失败计数短窗（L1）      | 10分钟内失败≥6次                | 进入L1保护期（15分钟）                     |
| 验证激活   | 失败计数中窗（L2）      | 24小时内失败≥15次               | 进入L2保护期（6小时）                      |
| 验证激活   | 7天阶梯升级（L3）       | 7天内高阶命中≥3次               | 进入L3保护期（72小时）                     |
| 验证激活   | IP风险加权              | 同设备24小时内IP去重数>8        | 在已有惩罚基础上提升一级（最高L3）         |
| 解除限制   | 需管理员介入            | 按邮箱或设备维度核实后处理      | 误操作可申请管理员介入                     |

备注：‘发送验证码’特指用户在注册页面点击“发送验证码”按钮。‘验证激活’特指用户在注册页面点击‘验证激活’按钮。

## 2·更新检查&下载封控规则（手动触发）

说明：以下规则仅作用于用户**手动触发**更新检查接口；

自动检查流程不计入本规则。并且，相关操作只能在用户完成验证并登录成功情况下才能正常使用。

| 模块           | 规则                 | 阈值                          | 触发后提示                         |
| -------------- | -------------------- | ----------------------------- | ---------------------------------- |
| 更新检查&下载   | 手动检测冷却         | 15秒                          | 提示剩余等待时间                   |
| 更新检查&下载   | 24小时阶梯限制（L1） | 24小时内手动更新检测次数>80   | 进入L1保护期（30分钟）             |
| 更新检查&下载   | 24小时阶梯限制（L2） | 24小时内手动更新检测次数>150  | 进入L2保护期（24小时）             |
| 更新检查&下载   | 24小时阶梯限制（L3） | 24小时内手动更新检测次数>180  | 进入L3保护期（72小时）             |
| 解除封控        | 需管理员介入         | 按邮箱或设备维度核实后处理    | 误操作可申请管理员介入             |

备注（当前受更新检查&下载封控规则影响的接口/按钮）：
1) 数据库下载页：执行在线数据库更新检查
2) 补丁包更新页：执行在线补丁包更新检查
3) 数据库卡片“打开链接”本身不单独计数；若该操作先触发手动检查接口，再按上述规则计入。
