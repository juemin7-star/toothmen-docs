# 云更新验证激活快速流程




说明：ToothMen_DentiPro_CH·云更新服务采用邮箱注册制，并与本地电脑CPU设备绑定。



## 一、快速注册账号流程



1. 验证码有效期为 5 分钟，且只能使用一次。
2. 点击“发送验证码”后，按钮会锁定 5 分钟，期间不能重复发送。
3. 发送后请直接粘贴验证码并点击“验证激活”，不要反复点发送。
4. 邮箱不限制发送次数；但同一台 CPU 设备 24 小时内最多发送 5 次验证码。

## 二、常见问题

Q1：为什么验证码还能过期？

答：验证码是一次性且有时效，超过5分钟或已使用都会失效。

Q2：我用了VPN会被直接封禁吗？

答：不会。系统以设备且高风险排查为主，IP只做风险辅因子，常规用户不会受影响。

Q3：出现“触发限制”怎么办？

答：按提示等待，优先使用已收到验证码完成验证，不要反复点击。
