# 云更新验证激活快速流程




说明：ToothMen_DentiPro_CH·云更新服务采用邮箱注册制，并结合设备维度进行风控保护。



## 一、快速注册账号流程



1. 验证码有效期为 5 分钟，且只能使用一次。
2. 点击“发送验证码”后，会进入 5 分钟冷却，期间不能重复发送。
3. 同一邮箱（服务端风控维度）24小时内：常规发送上限为 5 次；超过阈值会进入分级保护。
4. 发送后请直接粘贴验证码并点击“验证激活”，不要反复点发送。

## 二、常见问题

Q1：为什么验证码还能过期？

答：验证码是一次性且有时效，超过5分钟或已使用都会失效。

Q2：我用了 VPN 会被直接封禁吗？

答：不会直接因 VPN 封禁。系统以多维风控综合判断，IP 仅作为风险辅因子，正常使用不会受影响。

Q3：出现“触发限制”怎么办？

答：按提示等待后再试，优先使用已收到验证码完成验证，不要反复点击按钮。
