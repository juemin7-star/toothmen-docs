# 260321_V1.0更新说明



## 更新内容



1，重写剖面系统，按功能分为自由剖面与精确剖面。
2，解决两个系统交叉冲突核心问题。
3，两个插件均支持自由测量与测量值标准拖拽。
4，两个插件均内置专用雕刻工具，支持测量值刷新。
5，精确剖面支持双剖与独立调整。
6，重写截图插件，配合剖面测量。
7，剖面插件重写运算逻辑，减轻电脑消耗。
