# 260725-V1.3

正式发行版

## 更新内容

1，取消原M2版本矛隼数据，减少临床打印难度适配，进一步精简面板。

2，增加矛隼左右30度旋转控制按钮。

3，修正所有矛隼旋转应用问题，解决删除矛隼导致的圆心偏移不稳定问题。

备注：由于子父级关系限制，删除控制点依旧会产生矛隼子级偏移，已优化为世界坐标有序偏移。
