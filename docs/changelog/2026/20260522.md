# 260522-V2.0-Final大更新

2026北京国际口腔展前，最后封装模块。

## 更新内容



1，重新改写CBCT预览部分，支持，视口坐标调节，叠加剖面，叠加测量，增加剖面游标定点，以及几何中心定点支持，

全面适配自由ct查看， 适合关节区以及个性化钛钉，数字扩弓器等各场景内部的ct辅助查看。

2，重写数据对齐，支持一键初步对齐，一键优化对齐，支持对齐精度地图查看，增加对齐精度列表显示。

3，组合导板部分，重写套环布尔柱部分，支持视口直接选取，支持非循环边一键生成，适配非标准套管数据。

新增金属套管一键转换功能，适配金属导板打印。 小范围修复组合导板m2卯榫数据，

同时，强化布尔运算逻辑，避免下部导板结构个别布尔失败，增加2D方形杆数据库。

4，加入数字正畸模块，支持自由绘制金属带环，支持无窗/有窗，支持批量。

增加金属带环个性化打孔功能，增加TPU以及骨扩部分通用数据库。

5，常规导板部分增加3D曲线导板以及加强版3D涂绘导板,支持自定义调节公差与厚度。

6，通用打孔器部分，新增一键打孔，全面适配各种修复应用场景。

7，通用固位装置以及钛网固位钉系统数据库全面更新，各有10种预制规格。

8，重写布尔功能，支持单物体无限自由布尔。

9，数据中心新增公差制作器，满足数据外向公差精确制作。

10，黑金版新制作医工交互模块，支持无限网页预览与精确数值剖面，支持云空间数据存储与分享。支持手机版与电脑端适配。

11，自由剖面和精准剖面部分都支持角度和曲线测量功能，增加测量线删除功能。

12，倒凹观测功能优化，支持对非常规剖损数据预修复，减少倒凹填充失败，

同时，重构倒凹填充算法，对颌面以及邻接牙型部分取消网格重构，提高数据的运算精度与运算效率。

13，黑金版云更新管理器，增加医工交互界面。以及，云更新管理器，增加教学中心模块。
