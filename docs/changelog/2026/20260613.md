# 260613-V1.0-终版

2026北京国际口腔展后，最后封装模块-终版。

## 更新内容



1，重写数字正畸模块金属带环制作模块，现支持窗口直接绘制后进行编辑，支持自动窗体与主体绑定，支持自动识别有窗无窗结构，支持自判断，支持缓存生成新带环数据，同时，重命名生成集合与数据命名。

2，重写带环固位槽生成器，优化算法，大幅提高计算速度，实现了规则排列新方案，同时加入缓存和计算进度条显示。

3，添加专用正畸连接杆面板，转实体后自动细分，网格重构，适配模型。

4，重写曲线版常规导板，功能改进参考数字正畸的金属带环部分。同时，优化涂绘导板算法与面板。两种导板方案均支持仅提取面片，新增自由导板，支持反向自由生成导板。

5，通用打孔器，也重新改写，功能改进参考金属带环固位槽生成器。

6，新增快速布尔工具，界面一目了然，支持布尔减加公差。

7，新增无孔钛网花型，新增钛网合并进度指示条。

8，取骨导板切割与常规导板切割部分增加进度条。

9，修改视口距离，解决网格显示问题。

10，新增网格重构工具，支持一键体素与三角网格重构双功能。

11，重新编写场景记录与一键截图功能。同时，删除工具条窗口的截图功能。

12，组合导板修改粘膜数据认定错误。
