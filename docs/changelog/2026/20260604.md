# 260604-V1.0-终版

2026北京国际口腔展前，最后封装模块-终版。

## 更新内容



1，数据对齐新增对齐附加区域选择，增加复杂数据对齐便捷性，同时，数据对齐界面改版，修改部分参数，改进初步对齐和优化对齐参数，增加说明，解释各个参数意义。

2，重写数字正畸金属带环生成器的线段绘制部分模块，现支持3d视图绘制曲线，不影响3d视图旋转查看，同时，支持视口内直接双击编辑。默认厚度改为0.5。

3，更新常规导板3d曲线版功能，同正畸金属带环一样的性能改进。

4，新增加曲线连接正畸专用圆杆（默认直径1.7），，修复网格版曲线连接杆的调整功能。更改曲线连接杆的顶点直径，新增正畸专用数据。

5，数据处理中心，新增模型孔洞智能修复工具，支持对模型底部开放循环边延长及孔洞自动修复功能，支持视口对孔洞检查。支持一键补洞以及补洞区域自适应网格重构。

5，重修修改倒凹观测功能，倒凹观测与倒凹填充都不再支持孔洞修复功能，但增加了前期的检查弹窗，不合规禁止运行。

6，自由剖面，删除剖面坐标按钮，新增剖面90度旋转功能，解决部分剖面数据紊乱导致的剖面位置不对的问题。

7，重新调整3d窗口位置，解决画面中心不归零的问题。

8，纠正组合导板模块，对粘膜数据的厚度和重构逻辑解除。采用提前查找洞，不符合就终止。

9，底部边栏新增0.05三角网格重构，适配曲线编辑。

10，恢复组合导板通用布尔柱模块。
