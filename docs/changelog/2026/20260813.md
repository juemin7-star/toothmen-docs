# 260813-V1.0

免费版3D slicer配置管理器发行说明

## 更新内容

1·本配置管理器包含3部分：中文配置器，dentalsegementator配置管理器，slicer&blender数据桥接管理器。

2·中文管理器，采用在线和离线双方案，支持一键恢复英文原版。

3·dentalsegementator配置管理器，重点解决了，国内用户无法github连接进行安装的问题。解决的已知问题如下：



3·1解决安装过程的可视化，将安装过程进行重新梳理，一目了然，支持部分模块单独管理，解决原版统一下载，代码安装的不明朗问题。

3·2解决源代码的重要依赖项均采用国外下载源，提供2种国内下载源与1种官方下载源，解决需要翻墙或国外网络环境导致的不能下载与下载缓慢问题。

3·3解决源代码对权重强制连接Google与github的问题，提供2种解决方案，让国内用户可以百分百稳定使用。

3·4解决pip安装依赖项的问题，可自行进行依赖项目的检索梳理安装任务。

3·5提供权重在线查询与下载功能，确保能够跟官方实时保持更新联系。

3.6提供cuda与显卡驱动版本匹配性检测工具，方便进行问题排查。

3.7增加nnunet深度检测功能，修复官方依赖安装太浅bug。



4·slicer&blender桥接，支持数据双向传输。





## 特别说明

该三部分为永久免费
