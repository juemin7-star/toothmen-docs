# 260823-V3.0

正式发行版

## 更新内容

1，通用打孔器增加负向公差和生成柱体参数后调节。改变交互逻辑，改为单流程内的批量执行，单次提取立即关闭通道，防止误触。

2，通用连接杆模块，增加一键几何中心识别，配合高级玩法，可生成标准连接杆对接。

3，连接杆部分追增原点到几何中心前的应用变化，解决blender系统bug。同时追增了游标旋转归零，适配精确挤出。

4，修复打孔器底部法向混乱导致的布尔失败问题。

5，恢复视图的法向显示，便于排查网格表面问题。
