# NEW-26040901-补丁

你好，本次更新内容。

## 系统概述

ToothMen 是一款全面的牙科诊所管理系统，集成了患者管理、预约系统、病历记录、财务管理等核心功能，帮助牙科诊所实现全面数字化转型。

### 核心价值
- **提升效率**：自动化流程减少人工操作
- **改善体验**：为患者提供更好的就诊体验
- **数据安全**：多重备份和加密保护
- **合规管理**：符合医疗行业规范要求

## 快速开始

### 第一步：注册账户
访问 [https://toothmen.com/signup](https://toothmen.com/signup) 创建您的账户。

### 第二步：诊所设置
完成诊所基本信息配置：
1. 诊所名称和地址
2. 医生和护士信息
3. 治疗项目设置
4. 收费标准和套餐

### 第三步：添加患者
- 导入现有患者数据
- 手动添加新患者
- 批量导入Excel文件

### 第四步：开始使用
立即体验所有功能：
- 患者预约管理
- 电子病历记录
- 治疗计划制定
- 财务结算系统

## 核心功能模块

### 1. 患者管理
#### 患者档案
- 完整的个人信息
- 联系方式和工作单位
- 过敏史和病史记录
- 保险信息

#### 就诊记录
- 历次就诊详情
- 治疗项目和费用
- 医生诊断意见
- 下次复诊提醒

### 2. 预约系统
#### 在线预约
- 患者自助预约
- 微信小程序预约
- 电话预约登记
- 预约确认和提醒


#### 自动提醒
- 就诊前24小时短信提醒
- 微信消息推送
- 电话自动呼叫
- 邮件通知

### 3. 电子病历
#### 病历模板
- 标准病历格式
- 自定义病历模板
- 快速填写和保存
- 病历检索和统计

#### 影像管理
- X光片上传和查看
- CT扫描图像
- 口腔内窥镜照片
- 治疗前后对比

### 4. 财务管理
#### 收费管理
- 治疗项目收费
- 药品和材料费
- 套餐优惠设置
- 会员折扣

#### 财务报表
- 日/月/年收入统计
- 医生绩效报表
- 患者消费分析
- 应收账款管理
