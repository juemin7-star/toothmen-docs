# 示例图片占位文件

这是一个占位文件，你可以用实际的图片文件替换它。

## 如何添加图片

1. 将你的图片文件（如 `.png`, `.jpg`, `.svg`）复制到此目录
2. 在MDX文件中使用以下语法引用：

```markdown
![图片描述](/images/你的图片文件名.jpg)
```

## 示例图片命名

你可以创建以下示例图片：

1. **系统截图类**
   - `dashboard-overview.png` - 系统仪表板
   - `profile-system-interface.jpg` - 剖面系统界面
   - `mesh-reduction-tool.png` - 网格减面工具

2. **图表类**
   - `performance-comparison-chart.svg` - 性能对比图
   - `workflow-diagram.png` - 工作流程图
   - `architecture-overview.svg` - 系统架构图

3. **示意图类**
   - `window-mutex-mechanism.png` - 窗口互斥机制
   - `data-flow-diagram.svg` - 数据流程图
   - `update-roadmap.png` - 更新路线图

## 快速测试

创建一个简单的测试图片引用：

```markdown
![测试图片](/images/test-image.png)
```

然后在浏览器中查看效果。
