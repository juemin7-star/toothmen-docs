# ToothMen文档更新程序

一个用于管理ToothMen Docusaurus文档系统的桌面应用程序，提供双文件夹文件管理和自动化部署工作流。

## 功能特点

### 1. 双文件夹文件管理器
- **左侧**：`docs-测试中转`文件夹
  - 实时监控.mdx文件
  - 提供新建、删除、重命名按钮
  - 双击用系统默认程序打开编辑
- **右侧**：`docs`生产文件夹
  - 实时监控.mdx文件
  - 支持手动拖拽排序
  - 无新建/删除/重命名按钮（保护生产环境）
- **文件交换箭头**：在左右文件夹之间移动.mdx文件
  - 实际文件物理移动
  - 实时更新文件列表
- **上下移动按钮**：在生产文件夹中调整文件顺序
  - 上移按钮（↑）：将选中的文件上移一位
  - 下移按钮（↓）：将选中的文件下移一位
  - 自动保存文件顺序

### 2. 自动化部署工作流
- **更新侧边栏**：根据右侧文件列表顺序自动更新`sidebars.js`
- **本地构建测试**：执行`npm run build`测试构建
- **本地预览**：启动本地开发服务器预览
- **自动部署**：执行Git推送和Cloudflare部署

### 3. 用户界面
- **按钮状态反馈**：点击变颜色，成功绿色，失败红色
- **实时日志区域**：显示每个步骤的执行进程和结果
- **彩色日志输出**：不同级别日志使用不同颜色
- **进度指示**：显示操作进度
- **流程控制**：开始/结束按钮控制部署流程
- **步骤解锁**：上一步成功后才能执行下一步
- **智能布局**：文件管理区域紧凑，日志区域宽敞

## 系统要求

- **操作系统**：Windows 7/8/10/11
- **Python**：3.8或更高版本
- **Node.js**：需要安装Node.js和npm（用于构建）
- **Git**：需要安装Git（用于部署）

## 安装和使用

### 方法1：直接运行Python脚本
```bash
# 进入程序目录
cd ToothMen-dentipro-ch-文档更新程序

# 运行主程序
python main.py
```

### 方法2：打包为EXE（推荐）
```bash
# 安装PyInstaller
pip install pyinstaller

# 打包为EXE
pyinstaller --onefile --windowed --name ToothMenDocsManager main.py

# EXE文件将在dist目录中
# 复制到disc目录供使用
copy dist\ToothMenDocsManager.exe disc\
```

### 方法3：使用预编译的EXE
直接运行`disc\ToothMenDocsManager.exe`

## 使用流程

### 1. 文档创建和编辑
1. 在左侧"测试中转文件夹"点击"新建"按钮创建新文档
2. 双击文档用系统默认编辑器打开编辑
3. 使用"删除"或"重命名"按钮管理测试文档

### 2. 文档移动到生产环境
1. 在左侧列表选择要发布的文档
2. 点击"→"箭头将文档移动到右侧生产文件夹
3. 在生产文件夹中可以通过拖拽调整文档顺序

### 3. 部署工作流
1. **开始流程**：点击"▶ 开始部署流程"按钮
2. **更新侧边栏**：点击按钮根据生产文件夹顺序更新`sidebars.js`（成功后自动解锁下一步）
3. **本地构建测试**：点击按钮测试构建是否成功（成功后自动解锁下一步）
4. **本地预览**：点击按钮启动本地服务器预览效果（成功后自动解锁下一步）
5. **确认预览**：手动访问 http://localhost:3000 确认预览效果，然后点击此按钮确认（成功后自动解锁下一步）
6. **自动部署**：点击按钮执行Git推送和Cloudflare部署（成功后自动解锁下一步）
7. **验证部署**：点击按钮打开公网文档网站验证部署结果（成功后2秒自动结束流程）
8. **结束流程**：可随时点击"■ 结束流程"按钮终止部署流程

## 故障排除

### 常见问题

#### 1. 程序无法启动
- 检查Python是否安装：`python --version`
- 检查依赖：确保使用Python 3.8+

#### 2. 文件列表不显示
- 检查`docs-测试中转`和`docs`文件夹是否存在
- 检查文件夹权限
- 检查配置文件中的路径是否正确

#### 3. 构建测试失败
- 检查Node.js和npm是否安装：`npm --version`
- 检查项目目录是否正确
- 检查是否有构建错误（查看日志）

#### 4. 自动部署失败
- 检查Git是否安装：`git --version`
- 检查Git路径配置是否正确
- 检查网络连接
- 检查GitHub仓库权限

#### 5. 按钮状态不更新
- 检查日志输出
- 检查是否有未处理的异常
- 重启程序

### 日志文件
程序运行日志保存在`toothmen_docs_manager.log`文件中，可以通过日志诊断问题。
