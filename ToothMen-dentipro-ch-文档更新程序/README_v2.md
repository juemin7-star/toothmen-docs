# ToothMen文档管理系统 v2.0

## 🎯 全新功能

### 1. 文件夹分类管理
- **数字前缀排序**：文件夹和文件按数字前缀自动排序
- **树形结构显示**：直观的文件夹层级显示，支持展开/折叠
- **特殊文件夹处理**：`补丁更新日志`文件夹自动倒序排序

### 2. 文档结构要求
```
docs/
├── 1-产品文档/          ← 分类文件夹（数字-名称）
│   ├── 1-产品介绍.mdx   ← 文档文件（数字-名称.mdx）
│   ├── 2-使用指南.mdx
│   └── 3-常见问题.mdx
├── 2-技术文档/
│   ├── 1-API参考.mdx
│   ├── 2-部署指南.mdx
│   └── 3-故障排除.mdx
├── 3-更新日志/          ← 普通文件夹（正序排序）
│   ├── 1-v2.0更新.mdx
│   ├── 2-v1.5更新.mdx
│   └── 3-v1.0更新.mdx
└── 补丁更新日志/        ← 特殊文件夹（倒序排序）
    ├── 1-20240401-紧急修复.mdx  ← 数字最小，排最后
    ├── 2-20240315-功能优化.mdx
    └── 3-20240301-安全更新.mdx  ← 数字最大，排最前
```

### 3. 排序规则
- **文件夹排序**：按数字前缀从小到大（1, 2, 3, ...）
- **文件排序**：按数字前缀从小到大（1, 2, 3, ...）
- **特殊文件夹**：`补丁更新日志`文件夹内文件倒序排序（数字越大越靠前）

## 🔧 文件夹管理

### 添加新分类
```bash
# 在docs文件夹中创建新分类
mkdir "4-API文档"

# 添加文档文件
echo "# API文档" > "4-API文档/1-REST API.mdx"
echo "# GraphQL" > "4-API文档/2-GraphQL API.mdx"
```

### 调整顺序
```bash
# 调整文件夹顺序（修改数字前缀）
mv "2-技术文档" "1-技术文档"
mv "1-产品文档" "2-产品文档"

# 调整文件顺序
mv "2-使用指南.mdx" "3-使用指南.mdx"
mv "3-常见问题.mdx" "2-常见问题.mdx"
```

### 特殊文件夹
- **自动识别**：包含"补丁"、"更新记录"等关键词的文件夹
- **倒序排序**：文件按数字前缀从大到小排序
- **最新优先**：数字最大的文件排在最前面

## ⚙️ 配置说明

### 配置文件：`config_new.json`
```json
{
  "project_path": "项目根目录",
  "docs_folder": "docs",
  "reverse_order_folders": ["补丁更新日志", "更新记录"],
  "sort_by_number_prefix": true,
  "clean_number_prefix": true
}
```

### 自定义特殊文件夹
```json
{
  "reverse_order_folders": [
    "补丁更新日志",
    "紧急修复",
    "安全更新",
    "changelog"
  ]
}
```

## 🐛 故障排除

### 程序无法启动
1. **Windows Defender阻止**
   - 右键程序 → 属性 → 常规 → 勾选"解除锁定"
   - 或点击"更多信息" → "仍要运行"

2. **缺少Python依赖**
   - 运行`pip install -r requirements.txt`

3. **配置文件错误**
   - 检查`config_new.json`格式是否正确

### 侧边栏生成失败
1. **docs文件夹不存在**
   - 确保`D:\magicdental开发备忘录\toothmen-官方说明文档系统\ToothMen-Docs-Simple\docs`存在

2. **文件命名不规范**
   - 确保文件夹和文件使用"数字-名称"格式

3. **权限问题**
   - 确保有写入`sidebars.js`的权限

### 部署失败
1. **Git配置问题**
   - 检查Git是否安装并配置
   - 检查GitHub仓库权限

2. **网络连接问题**
   - 检查网络连接
   - Git推送失败时会保存提交到本地

### 常见问题
1. **Q：如何添加新的特殊文件夹？**
   A：在`config_new.json`的`reverse_order_folders`中添加文件夹名称

2. **Q：文件夹排序不正确？**
   A：确保使用"数字-名称"格式，如"1-产品文档"

3. **Q：文件显示顺序错误？**
   A：检查文件命名格式，确保使用"数字-名称.mdx"

4. **Q：侧边栏没有分类？**
   A：确保docs文件夹中有子文件夹，且包含.mdx文件
