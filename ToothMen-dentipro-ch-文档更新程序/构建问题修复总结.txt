`docusaurus.config.js` 文件被错误地写入了MDX文件的内容，而不是JavaScript配置文件。

**错误的文件内容**（MDX格式）：
```mdx
---
id: changelog-index
title: Denti-Pro更新日志总览
sidebar_label: 更新日志总览
---

# Denti-Pro更新日志总览

```

**正确的文件内容**（JavaScript格式）：
```javascript
// @ts-check
/** @type {import('@docusaurus/types').Config} */
const config = {
  title: 'ToothMen文档系统',
  // ... JavaScript配置
};
```
