
2. **扩展名智能处理**
   ```python
   # changelog文件夹使用.md扩展名
   if folder_name == "changelog":
       config_file_with_ext = f"{config_file}.md"
   # 其他文件夹使用.mdx扩展名
   else:
       config_file_with_ext = f"{config_file}.mdx"
   ```

3. **clean_name方法增强**
   ```python
   # 原代码（仅支持.mdx）:
   if name.endswith('.mdx'):
       return name[:-4]
   
   # 新代码（支持.mdx和.md）:
   if name.endswith('.mdx'):
       return name[:-4]
   elif name.endswith('.md'):
       return name[:-3]
   ```
